# 1.1.1 — Empty owner-identity map decoding

The compact free-float-events decoder now omits an event's
`ownerIdentitiesMap` when its reconstructed owner-identity state is empty,
matching the legacy full producer. Previously it inserted an empty dictionary.
This covers both an empty initial state and deletion of the last identity;
nonempty identities still carry through sparse events and can be reintroduced.

Other mapping fields, event ordering, values and numeric types, split/basis
fields and component-deletion details are unchanged. Already-expanded full
payloads retain their original field presence. No API payload format changed.

Validation includes the full offline client suite and exact comparisons against
independently produced compact/full fixtures. Financial fixtures and source
material are not included in the distribution.
